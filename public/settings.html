What it does

  • Generate Context: click Pikachu (or + → Generate Context) to capture the entire current conversation — including history loaded via scrolling — as Markdown.
  • Upload Context: switch to another supported LLM, click + → Upload Context, and the last generated context is automatically inserted into that chat's input. No file picking, no drag-and-drop, no copy-paste.
  • Capsules: save reusable blocks of context (goals, project background, style guides) from the popup or Library.
  • Folders: group Capsules any way you want (Engineering, Marketing, Personal…).
  • Cook This Prompt: a local, rule-based prompt enhancer — Role · Task · Constraints · Output, step-by-step reasoning, audience, output format, and more. No API keys.
  • Right-click to save: highlight any text on any page → Save selection as Capsule.
  • JSON backup: import / export your Capsules and folders as a portable file.

Privacy pillars

  • ❌ No account, no cloud sync, no analytics, no telemetry.
  • ❌ No third-party API calls; zero runtime dependencies in the shipped extension.
  • ✅ Generated context and Capsules stay in this browser's storage. Wipe them any time with the button above.

Safety guarantees

  • Never bypasses site authentication, CSP, CORS, DRM, or any security mechanism.
  • Generate Context does read the visible conversation text on the page in order to capture it — that's the feature. It is never transmitted anywhere except this browser's own local storage, and only runs when you click Pikachu or Generate Context.
  • Upload Context only reads back the context you already generated and types it into the current page's chat input — nothing is sent over the network by the extension itself.
  • If a full history can't be confirmed (extremely long or oddly-loading conversations), the extension marks the result "possibly incomplete" rather than silently pretending it captured everything.
  • Least-privilege permissions: storage, activeTab, scripting, contextMenus, plus host permissions for the supported AI sites only.

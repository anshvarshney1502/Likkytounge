What it does

  • Capsules: save reusable blocks of context (goals, project background, style guides).
  • Folders: group Capsules any way you want (Engineering, Marketing, Personal…).
  • One-click inject: on ChatGPT, Claude, Gemini, DeepSeek — open the picker with Alt+K, click a Capsule, and its text lands in the chat input.
  • Drag & drop: grab a Capsule tile and drop it onto any chat input.
  • Cook This Prompt: a local, rule-based prompt enhancer. Structures your prompt into Role · Task · Constraints · Output, asks for step-by-step reasoning, sets audience, and more — no API keys.
  • Right-click to save: highlight any text on any page → Save selection as Capsule.
  • JSON backup: import / export the whole vault as a portable file.

Privacy pillars

  • ❌ No account, no cloud sync, no analytics, no telemetry.
  • ❌ No third-party API calls; zero runtime dependencies in the shipped extension.
  • ✅ Every Capsule stays in this browser's IndexedDB. Wipe it any time with the button above.

Safety guarantees

  • Never bypasses site authentication, CSP, CORS, DRM, or any security mechanism.
  • The launcher is UI-only — it doesn't read chat contents or send anything anywhere.
  • Least-privilege permissions: storage, activeTab, scripting, contextMenus, plus host permissions for the supported AI sites only.

    What it does

    • One-click save of the current AI conversation from ChatGPT, Claude, Gemini, and other chat sites.
    • Captures messages, roles, order, code blocks (with language), links, and lists — plus attached images and files.
    • Stores everything only in this browser (IndexedDB); exports as JSON, Markdown, plain text, HTML, or a ZIP archive.
    • Backup / restore your whole vault as a portable ZIP — no cloud in the middle.

    Privacy pillars

    • ❌ No account, no login, no cloud sync.
    • ❌ No analytics, no telemetry, no tracking pixels.
    • ❌ No third-party AI/API calls; zero runtime dependencies in the shipped extension.
    • ✅ All data stays on this device. You can wipe it any time with one click.

    Safety guarantees

    • The extension never tries to defeat authentication, CORS, CSP, DRM, or any site security.
    • The content script is passive — it only acts when the popup asks, never observes on its own.
    • Least-privilege permissions: activeTab, storage, scripting, clipboardWrite, plus host permissions for the supported AI domains only. No <all_urls>.
    • Debug mode logs counts and warnings only — never message contents.
